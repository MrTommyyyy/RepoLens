# Contributing to RepoLens

Small reproducible bugs and focused improvements are welcome. Include the tool version, operating system, command and a synthetic example. Never attach real credentials or private configuration.

Run `python -m unittest discover -s tests -v` before proposing a change. Keep normal operation offline, document behaviour and exit codes, and add a regression test for a bug that could recur.

Useful next steps: clearer output for edge cases, more real-world syntax/filename examples and feedback on terminal usability. Discuss larger scope changes in an issue first.
