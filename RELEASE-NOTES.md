RepoLens 0.1.0 is an offline developer tool for project sizes, largest files, text lines and CI size budgets.

Extract the Windows-x64 ZIP and run RepoLens.exe from a terminal. Python is bundled. The source ZIP requires Python 3.11+ and works on Windows, macOS or Linux. This release has no desktop GUI.

Validation: 9 source tests and packaged executable checks with synthetic inputs. See README for commands, output handling and practical limits. SHA256SUMS.txt lists executable hashes.
